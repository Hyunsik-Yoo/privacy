개인정보 처리방침

시행일: 2026년 4월 3일

"날 - 디데이 위젯"(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 개인정보 보호법에 따라 다음과 같이 개인정보 처리방침을 안내드립니다.

1. 수집하는 개인정보

본 앱은 어떠한 개인정보도 수집하지 않습니다.

  • 회원가입, 로그인 기능이 없습니다.
  • 서버로 데이터를 전송하지 않습니다.
  • 제3자에게 데이터를 공유하지 않습니다.
  • 분석, 광고, 추적 도구를 사용하지 않습니다.

2. 기기 내 데이터 저장

앱에서 생성하는 디데이 정보(제목, 날짜, 배경 이미지 등)는 사용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.

  • 데이터는 기기 내 로컬 저장소에 보관됩니다.
  • 위젯 기능을 위해 App Groups 공유 컨테이너를 사용하지만, 이는 기기 내부에서만 동작합니다.
  • 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

3. 사진 라이브러리 접근

디데이 배경 사진 설정을 위해 사진 라이브러리 접근 권한을 요청할 수 있습니다.

  • 선택한 사진은 기기 내에서만 사용되며, 외부로 전송되지 않습니다.
  • 사진 접근은 사용자가 직접 선택한 사진에 한해서만 이루어집니다.

4. 아동의 개인정보

본 앱은 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.

5. 개인정보 처리방침의 변경

본 방침이 변경되는 경우, 앱 업데이트 또는 본 페이지를 통해 안내드립니다.
